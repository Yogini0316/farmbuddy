# 🌾 FarmBuddy

**FarmBuddy** (previously "CROPIFY") is an agricultural e-commerce web application that connects farmers and buyers through a simple and effective digital platform.

---

## 🛠️ Built With

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP
- **Database**: MySQL
- **Admin Dashboard**: PHP-based with tools for managing crops, users, and orders

---

## 🌟 Features

- 👩‍🌾 **Farmer Registration/Login**
- 🛒 **Crop Listings**: View and add crops for sale
- 🧾 **Dynamic Subtype Filtering** (AJAX)
- 📦 **Order Management** (Admin)
- 🔐 **Secure Login for Admin and Users**
- 📊 **Dashboard** for Admin Controls
- ❌ 404 Error Handling Page
- 🎨 Responsive UI (HTML templates)

## 🗄️ Database Setup

1. Create a MySQL database named `farmbuddy` (or use your preferred name).
2. Import the SQL file (if available) into your DB:
   
   USE farmbuddy;
   -- import tables for users, crops, orders, etc.
   
🚀 Getting Started

Clone the repository:

git clone https://github.com/Yogini0316/farmbuddy.git
Place it in your local server folder (e.g., htdocs for XAMPP).

Start Apache and MySQL from XAMPP.

Access it at:

http://localhost/farmbuddy/
